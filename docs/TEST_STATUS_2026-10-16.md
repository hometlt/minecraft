# Проверка перед коммитом — 16.10.2026

Пользователь явно разрешил коммит и отправку в `main` с перечисленными ниже
ошибками. Они не исправлены этим коммитом. Проверки на чистом исходном baseline
не проводились, поэтому происхождение ошибок не установлено.

`compileJava` и `compileClientJava` прошли. Полный `runGametest` завершился
с ошибкой: **198 тестов, 194 прошли, 4 упали**. Все 9 тестов структур прошли.

| Тест | Наблюдаемая ошибка |
| --- | --- |
| `PathfindingGameTests.workersTunnelThroughAMountain` | Осадный танк застрял в сценарии прокладки туннеля через гору. |
| `MiningGameTests.scvsKeepMiningForMinutes` | Недостаточная скорость добычи КСМ: 106, 76, 206, 132 минерала в минуту. |
| `PlatformGameTests.aCalledTransportFoundsTheBase` | После вызова транспорта отсутствует командный центр базы. |
| `VespeneGameTests.scvPumpsABareOutlet` | КСМ не добыл веспен из открытого выхода: 0 веспена. |

Команда проверки (пути вывода и кэша задавались вне репозитория):

```text
gradlew compileJava compileClientJava runGametest --offline --no-configuration-cache --console=plain
```

Отдельно проверены личная сборка с исходными моделями и соответствие ресурсов
в JAR; все 115 исходных и 115 воксельных моделей прошли Java reader/pose проверки.
Это не подтверждает исправность четырёх сценариев выше или визуальную точность
всех моделей в игре. Производные ассеты StarCraft II в коммит не включены.
