# Способности юнитов (план, владелец 14.10.2026)

Источник — мультиплеер SC2 LotV, только юниты, которые есть в моде. Приоритет: **1** — без неё юнит
играет не так, как в SC2; **2** — заметно добавляет тактики; **3** — потом. Числа (энергия, время,
урон, дальность) берутся из данных SC2 и пересчитываются, как остальные (`UnitKind`: урон ×10/35,
дальность ×1,153 блока).

Уже есть: взрыв гиблинга, линия шипов скрытня, выводок властелина, саранча носителя роя, замедление
заразителя, затягивание вайпера, лечение медэвака, переливание королевы, перевозка повелителем, удар
ультралиска по площади.

## Общие механики (делаются первыми)

1. **Энергия** — шкала у юнитов-заклинателей, восстановление по SC2, показ в интерфейсе.
2. **Невидимость и обнаружение** — невидимых не видят и не бьют, кроме тех, кого видит детектор
   (надзиратель, споровая колония, ракетная турель, фотонная пушка, наблюдатель, оракул, сканирование).
3. **Режимы юнита** — смена облика и атаки (осадный танк, викинг, геллион/геллбат, закапывание, призма).
4. **Каналы и отложенные удары** — Ямато, прицельный выстрел, желчь, шторм, ядерный удар.
5. **Перевозка** — медэвак, призма, бункер на основе перевозки повелителем.
6. **Карточка команд и ИИ** — кнопки способностей с горячими клавишами SC2, наведение на точку или
   цель; ИИ диких баз применяет способности по простым правилам.

## Сделано (14.10, пакет `ability`)

Все способности из таблиц ниже реализованы на общем движке (облачный агент, 14.10; отказ «пока не
готово» и список `READY` удалены). Тесты — `ability/MechanicsGameTests`, `ZergAbilityGameTests`,
`TerranAbilityGameTests`, `ProtossAbilityGameTests` и прежний `AbilityGameTests`.

| --- | --- | --- |
| Список способностей | `Ability` | цифры SC2 (энергия, перезарядка, дальность, канал, задержка, ресурсы базы), прицел: без цели, переключатель, юнит, точка; кто владеет |
| Движок | `Abilities` | проверка (энергия, перезарядка, здоровье, ресурсы, занятость, состояния, допустимая цель), оплата, мгновенно / после канала / с задержкой / сменой режима; приказ игрока: переключатели и простые — всем выбранным, прицельные — ближайшему способному, вне досягаемости — подходит и применяет (и для точки, и для юнита); способности здания по его облику (`Abilities.shown`) |
| Энергия | `StarUnit` (синхронизируется), `UnitKind.maxEnergy/startEnergy`, `StarUnit.maxEnergy` | восстановление 0,7875 в секунду; у орбитальной станции 200 |
| Временные состояния | `Status` | стимулятор, замедление, обездвиживание, ослепление, защитное поле, подъём, стазис, слияние, канал, нейропаразит, барьер, форсаж, призматическое выравнивание, раскрытие, маскировочное поле, ускорение времени, разгон батареи, впрыск, временный призыв, галлюцинация; скорость и оружие пересчитываются (`StarUnit.refreshWeapon`), сохраняются в NBT; игроку в теле юнита — то же на юните и ванильный эффект на теле |
| Невидимость и обнаружение | `Cloak`, миксин видимости | маскировка за энергию, постоянная (тёмный храмовник, наблюдатель), бесплатная (закопанные, поле материнского корабля); детекторы, сканирование (на стороне, 12,3 с), откровение |
| Режимы | `Modes` | осада, закапывание, посадка викинга (навигация, гравитация, полёт игрока), геллбат (здоровье, «биологический»), фаза призмы (энергия как пилон), пульсирующий луч, полезная нагрузка тора, опущенный склад, варп-врата, техлаборатория и реактор, орбитальная станция и планетарная крепость; время смены по SC2 |
| Пассивы | `Passives` | бонусный урон SC2 по лёгким/бронированным, сотрясающие снаряды, поджог геллбата, защитное поле, барьер, батарея щитов, перехватчики, маскировочное поле, реген закопанного таракана, расход энергии пульсирующего луча |
| Длительные каналы | `Channels` | гравитонный луч, едкий спрей, нейронный паразит |
| Отложенные эффекты | `Delayed` | в памяти сервера (секунды): удары, импульсы шторма, облака, ловушки |
| Перевозка | `Transport` | медэвак, призма, повелитель — 8 мест; бункер — 4 места пехоты, стреляют изнутри; груз неуязвим |
| ИИ | `AbilityAi` | правило для каждой способности (диких юнитов, раз в секунду) |
| Интерфейс | `CommandScreen` | кнопки в нижнем ряду карточки, горячие клавиши SC2, подсказки с энергией и перезарядкой |

## Упрощения

- Ядерный удар — урон по SC2 (300 и +200 по зданиям в центре, меньше к краю, всем); блоки разрушаются
  только при правиле игры `starmineNukeGriefing` (по умолчанию выключено).
- Нейронный паразит — временное переподчинение, пока заразитель держит канал (до 11 с): юнит воюет за
  сторону заразителя (`Faction`); обычное существо нападает на врагов заразителя. Без управления игроком.
- Подменыш — юнит, которого враги не трогают (150 с); облик жителя или игрока (этап 7а улья) — позже.
- Галлюцинация — всегда два фанатика-иллюзии (наносят 0 урона, получают двойной, исчезают через 43 с).
- Едкая желчь и ослепляющее облако задевают только врагов; радиус желчи — 1,5 блока (в SC2 0,5 —
  попасть в Minecraft было бы почти невозможно). Желчь плавит силовые поля, а при `mobGriefing` — лёгкие
  блоки (листва, стекло, растения).
- MULE — временный КСМ своей базы (64 с), каждая его доставка минералов засчитывается вчетверо.
- Варп-врата — юнит обучается в очереди врат как обычно, но появляется в точке сбора, если она в поле
  пилона или призмы; время обучения не меняется.
- Стазисная ловушка, шторм, облака, временная дыра — в памяти сервера (длятся секунды–минуты); при
  перезапуске сервера пропадают. Силовое поле исчезает через запланированный тик блока и переживает
  перезапуск. Временные состояния юнитов (стимулятор, впрыск, галлюцинация…) сохраняются с юнитом.
- Режим орудий тора: 40 урона, дальность 11, 0,91 с (без деления на «по массивным» и «по лёгким»).
- Перехватчики у дикого авианосца строятся бесплатно, у авианосца базы — по 15 минералов.
- Полёт зданий терранов — трудно с постройками из сущностей, отложено (кнопки нет).
