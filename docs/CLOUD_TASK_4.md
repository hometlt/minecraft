## 2. Модели: новые формы и проверка старых

`tools/sc2-export/kinds.mjs` читает `docs/sc2-models.json`.

1. **Новые формы с 19.10** (`death: false`):

   | Форма | Юнит SC2 |
   | --- | --- |
   | `spinecrawler_uprooted` | SpineCrawlerUprooted |
   | `sporecrawler_uprooted` | SporeCrawlerUprooted |
   | `overseer_oversight` | OverseerSiegeMode |
   | `observer_surveillance` | ObserverSiegeMode |

   - Клипы стойки и ходьбы подобрать так же, как для прежних форм — таблица `FORMS` в `starmine-export/kinds.mjs`.
   - Клиент сам подхватывает модель формы. Теперь он перебирает все режимы до `Modes.LAST`, а раньше только до
     большого шпиля.
2. **Формы новых режимов без своей модели SC2:**
   - мешки повелителя (`overlord_sacs`, юнит OverlordTransport) — проверить, что эта модель есть;
   - режим выделения слизи (CREEPING) своей модели не требует, его рисуют обычной моделью.
3. **Проверка `build.gradle`:** каждая модель из списка либо сконвертирована, либо названа в `unavailableModels` с
   причиной. Абатур, Свонн и Хорнер по-прежнему без модели, если не найдены в `AlliedCommanders.SC2Mod`.

## 3. Цвета команд (главное в этой задаче)

Мод сам красит каждую сторону своим цветом:
- дикие зерги — `#8A2BD0`, терраны — `#2060FF`, протоссы — `#EBD129`;
- Амун — `#B4141E`, хранители зел-нага — `#1CA7EA`;
- игроки — цвета SC2 по UUID.

Сейчас экспорт запекает цвет расы в текстуры, и модель SC2 всегда остаётся в цвете своей расы. Нужно так:

1. **Текстуры без запечённого цвета команды.** Диффуз экспортировать без подкраски (`teamColor(kind)` из `kinds.mjs`
   теперь только для превью).
2. **Маска рядом с каждой текстурой, где есть цвет команды:** `textures/entity/sc2/<текстура>_team.png`.
   - RGB — серая светотень диффуза в этой зоне (яркость; цвет мод даст сам);
   - A — маска цвета команды: альфа диффуза SC2 / слой team color материала M3 (как SC2 смешивает цвет команды);
   - пиксели вне зоны — полностью прозрачные;
   - суффикс — `TEAM_MASK_SUFFIX` из `kinds.mjs`.
3. **Воксельный режим.** Текстура там `<вид>_voxel.png`, поэтому маска — `<вид>_voxel_team.png`: та же раскладка
   атласа, альфа — доля цвета команды у вокселя.
4. **Как это рисует мод:** `client/SkinnedModelDrawer.drawTeam` — второй проход по частям, у которых есть маска,
   `entityTranslucent(маска)` цветом стороны. Нет маски — модель рисуется как есть.
   - Проверить в игре: маска не мерцает (z-fighting) и не темнит модель.
   - Если мерцает или темнит — поправить в моде (например, свой `RenderType` с `LEQUAL` и `polygonOffset`) и описать
     в отчёте.
5. **Проверка.** Расширить `tools/check_model_package.ps1`: посчитать маски и перечислить модели с текстурами без
   маски. Здания и юниты SC2 почти все имеют цвет команды; без маски — только то, где его правда нет.

1. Экспорт: `export-starmine-sounds.mjs`, язык `--voice-locale` (по умолчанию английский).
2. Проверка: `python3 tools/check_sounds.py <sc2-assets>`. Список событий вырос до 705. Новые события способностей:
   - `ability.microbial_shroud`, `ability.uproot`, `ability.generate_creep`;

3. Найти звуки каста в данных SC2: кнопки — в `race/Sc2Buttons.java`, звук обычно у эффекта или актёра способности.
   - Добавить их в таблицу экспортёра.
4. **Звуки, которых в SC2 нет** (выстрелы юнитов без оружия, способности без звука каста):
   - в отчёт — списком;
   - где у похожей способности звук есть, можно взять его, но это записать.
5. Прошлый результат — 473 из 666 событий. Цель — все события, у которых в SC2 есть звук.

## 5. Собрать версию на тест

1. Экспорт из установленной SC2 владельца в `sc2-assets/`: модели в двух режимах (исходные и `voxel`) с масками
   цвета команды, значки (`export-starmine-icons.mjs`), звуки.
2. Сборка личных JAR:
   `gradlew build -PincludeSc2Assets -PstarmineModelMode=voxel -PstarmineAssetsDir=<sc2-assets>`, и так же
   с `original`.
3. Проверка архивов: `tools/check_model_package.ps1`, маски тоже.
4. Ассеты SC2 и личные JAR **в git не класть.** Положить их вне репозитория, например в `C:\MKTEMP\starmine-1910`, и
   назвать путь в отчёте.
5. Изменения кода мода (генераторы, правки рисования, отчёт) закоммитить в `main` и отправить в `origin main`.
   Изменения ModKit — по правилам его рабочего пространства (vendor hop при изменении публичного API ядра).
6. `tools/run_gametests.sh` на итоговом коммите — light и heavy, оба результата в отчёт.

## 6. Ручная проверка для владельца (список в отчёт)

1. **Цвета команд:**
   - дикие зерги фиолетовые, терраны синие, протоссы жёлтые, войска Амуна красные;
   - свои юниты — цветом игрока, на моделях и на миникарте;
   - метки баз на миникарте — в цветах сторон.
2. **Новые способности:**
   - заразитель ставит завесу;
   - ползун выкорчевывается, ползёт по приказу и укореняется только на слизи (модель формы);
   - повелитель выделяет слизь, когда у игрока есть логово;
   - надзиратель заражает здание и переходит в надзор (модель формы), наблюдатель — в наблюдение;
   - орбитальная станция делает сброс припасов на склад.
3. **Оружие против воздуха:**
   - тор переключает режим;
   - королева, крейсер и буреносец бьют по воздуху своим оружием;
   - ракеты освободителя разлетаются.
4. **Нейропаразит:** захваченным юнитом можно командовать.
5. **Подменыш:**
   - среди чужой армии выглядит как её солдат;
   - у игрока без армии — как этот игрок;
   - в деревне — как житель.
6. **Ядерный удар:** гриб дыма и воронка; пехотинцы гибнут, тор выживает.
7. **Наёмники:**
   - у шерифа три контракта;
   - рота высаживается рядом;
   - над юнитами имя роты.
8. **Справочник:** разделы, страница «Цели» с подсказками; книга крафтится из книги и осколка минерала.
9. **Звуки** новых способностей.
