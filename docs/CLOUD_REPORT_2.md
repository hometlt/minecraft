## Этап 1. Масштаб юнитов

Юниты вдвое крупнее модели (`UnitKind.UNIT_SIZE = 2`, владелец 15.10). Все 8 красных тестов из §0
починены, а заодно — места, где размеры и расстояния были записаны числами под старый рост (их нашёл
обход кода: 44 места, ниже — что исправлено).

Решение по хитбоксам — владельцу: хитбокс — размер модели ×2, поэтому тор 10×11, колосс 7×14,8,
сталкер 4,4×6,2. По радиусу столкновения SC2 (марин 0,375, тор 1,25 единицы) тор был бы около 5,8 блока
шириной. Путь для тора через гору — 1485 блоков. Менять не стал: это решение владельца из
коммита масштаба.
