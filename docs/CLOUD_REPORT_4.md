## 2. Конвертер моделей

### Список берётся из мода

Установщик (прототип `parked/GAME-MINECRAFT/starmine-export` и `voxel-preview/starmine-all.mjs`) больше не держит своего
списка. `starmine-export/kinds.mjs` импортирует `<StarMine>/tools/sc2-export/kinds.mjs` (путь — `--starmine` или
`STARMINE`, `ONLY=...` работает через `selected()`). В установщике осталось только то, чего в списке мода нет:

- имена клипов атак и гибели SC2 у отдельных юнитов;
- клипы форм: в чём стоит и ходит форма.

Здание это или юнит, установщик берёт из данных SC2 (`Unit.Attributes[Structure]`).

- **Свой мод у каждой модели.** Обзор, чтение файлов и текстур открывают контекст мода или кампании самого юнита, через
  загрузчик модов (`ContentSources.openModContext`). Например, герои — `VoidStory`/`SwarmStory`/`LibertyStory`.
- **Формы.** Почти все используют модель и актёр основного юнита, но стоят в своём клипе:

  | Форма | Клип |
  | --- | --- |
  | орбитальная станция | `Stand A` |
  | планетарная крепость | `Stand B` |
  | взлетевшие здания | `Fly Stand` / `Fly Walk` |
  | опущенный склад | `Stand Burrow` |
  | врата искривления | `Stand Superior` |
  | защитник | `Cover` |
  | фазовая призма | `Stand Work` |
  | Тор в режиме high impact | `Morph Stand` |
  | закопанные | `Stand Burrow`/`Burrow Stand`, иначе последний кадр `Burrow` (новое поле `hold` в `smm.mjs`) |

- **Цвет команды.** Берётся из списка мода: зерги `#C060FF`, терраны `#60A0FF`, протоссы `#FFD040`.
- **Анимации.** В модель идут все RequiredAnims модели (раньше только первая). Модели гибели делаются только для записей
  с `death: true`.
